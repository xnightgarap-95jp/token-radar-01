How the radar ranks

Implied value = TVL × category multiple × growth factor × age factor. Growth uses the snapshot's own 7-day TVL change, clamped to ±25%. Age uses how long DefiLlama has tracked the protocol with no token recorded — a long pre-token record scores higher. The multiples are set by category, never by name, and every figure comes from the sealed snapshot. A protocol here records no token; that is DefiLlama's record, not proof it has none.
